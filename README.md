# shop_projects

A collection of standalone projects and utilities for the shop.

Each folder is a self-contained tool, and each builds down to a single HTML file
you open in a browser — no internet, no install, works off a USB stick.

## Projects

- **[shelf_talkers/](shelf_talkers/)** — type item names and prices into a
  table, pick a design and a grid, print shelf-talker price cards onto A4.
  Replaces the old Microsoft Publisher templates.

- **[image_grid/](image_grid/)** — drop in a set of images, arrange them on an
  A4 grid, export a print-ready PDF. Contact sheets, label batches, anything you
  want several up on one page.
